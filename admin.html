🚀 部署教學 · 升級指南 · 版本管理 v0.5.2 ▸

首次部署（v0.5 全新）

1在 Google Sheets 建立新試算表，命名「農業綠能輿情系統」。
2開啟 Apps Script，將檔案複製到對應位置：主程式.gs、index.html、admin.html、arguments.html。
3在 Script Properties（⚙️ 專案設定 → 指令碼屬性）新增以下屬性：
  • CLAUDE_API_KEY — Anthropic API 金鑰
  • WEB_PASSWORD — 候選頁密碼，預設 GREEN ENERGY
  • ADMIN_PASSWORD — 主控台密碼，預設 CPWU
  • PROMPT_DOC_ID — AI判斷規則.md 的 Drive 檔案 ID
  • KB_DOC_ID — 知識庫.md 的 Drive 檔案 ID
  • ADMIN_EMAIL — 錯誤通知信收件地址
4執行一次 setupSheets() 函式以建立所有分頁。
5部署為 Web App：執行身分 = 部署者、存取 = 所有人。取得 URL 後以 ?page=candidates&key=GREEN ENERGY 分享給團隊，?page=admin&key=CPWU 留給管理員。
6設定觸發器：dailyCollect，時間驅動，每天 15:00（Asia/Taipei）。

v0.5.2 加入 7 項新功能：URL 黑名單、主表去重、新聞日期改 pubDate、手動新增新聞、判斷規則分段編輯、論點萃取器、給長官參考、email 模板重做。
  • 替換 AppsScript_主程式.gs、index.html、admin.html 全文。
  • 執行一次 setupSheets()：候選輿情會自動補上「給長官參考」欄；輿情主表也會自動補上同欄。
  • 重新部署一個新版本，URL 不變。不需新增任何 Script Property。
  • 黑名單可改填網域字串如 msn.com，會同時比對來源名稱與新聞 URL。

v0.5.2 操作要點

  • 主表去重：每次抓取會自動排除主表近 3 天已存在的新聞（用標題正規化比對）。
  • 新聞日期：候選顯示與晉升到主表的日期改為 RSS 的新聞發布日（pubDate），不再是執行日。
  • 手動新增：候選頁右上「＋ 新增新聞」可貼連結（系統抓內文）或貼標題+內文，自動跑 AI 分析。
  • 判斷規則：主控台拆成兩個分頁（STAGE_1 / STAGE_2），純文字編輯，變數可點按鈕插入。進階直接編輯原始 .md 的入口仍保留。
  • 論點萃取器：主控台 §5。貼新聞＋你寫的稿，AI 分析你用了哪些既有論點、有哪些是新論點，逐則編輯後 append 到指定議題分類。
  • 給長官參考：候選卡片右下核取＝給長官參考（email 顯示黑字、不納入週/季輿情統計）。未核取＝紅字（綠能正式輿情）。
  • Email 模板：6 欄寬度依範本、序號每日期區段重算、白/灰底依日期、紅/黑字依「給長官參考」、主旨「【每日輿情回報】YYYY/M/D 農業綠能」。

取得 Drive 檔案 ID

在 Google Drive 開啟 .md 檔，URL 中 /d/ 後、/edit 前的一串亂碼即為 File ID。

常見問題

  • AI 分析 529 錯誤：Anthropic API 用量高峰。系統會標記「AI用量高峰，分析失敗，請人工確認」並保留候選，可在候選頁點「AI 分析」手動補跑。
  • Gmail 寄信失敗：確認 Apps Script 已授予 Gmail 範圍；設定_寄送名單需有啟用的收件人。
  • 主控台無法讀取知識庫：確認 KB_DOC_ID 與 PROMPT_DOC_ID 已設定，且部署者對該 Drive 檔案有讀寫權限。
  • 執行時間超過 6 分鐘：系統有 4.5 分鐘保險絲，逾時新聞保留 pending 狀態，候選頁手動逐則補跑即可。
