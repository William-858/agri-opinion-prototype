草生栽培幫手 — 網頁App說明
================================

這個資料夾包含4個檔案:
- index.html    App本體(拍照→AI判讀→農民自評→建議,全部都在這個檔案裡)
- manifest.json 讓手機瀏覽器可以「加入主畫面」變成一個圖示
- icon-192.png / icon-512.png  App圖示

一、怎麼讓農民手機上出現「圖示」
--------------------------------
1. 把這4個檔案原封不動放在同一個網址底下(例如放到你們自己的網站,
   或用免費的靜態網站服務,如 GitHub Pages、Netlify、Vercel,把整個
   資料夾拖上去即可,幾分鐘內就能拿到一個 https 網址)。
   *必須是 https 網址,http 或本機檔案沒辦法完整運作「加入主畫面」。*
2. 農民用手機瀏覽器(Android用Chrome、iPhone用Safari)打開這個網址。
3. Android(Chrome):選單 → 「新增至主畫面」或「安裝應用程式」。
   iPhone(Safari):下方分享圖示 → 「加入主畫面」。
4. 手機桌面就會出現一個綠色的圖示,點下去會像開App一樣全螢幕開啟,
   網址列不會出現,一般人不會發現這其實是網頁。

二、目前做到什麼程度、還缺什麼(這段給你們自己看,不會顯示在App上)
--------------------------------
已經完成、可以直接示範/測試的部分:
- 拍照(手機相機直接開啟)
- 農民自評選擇題
- 依規則產生的耕作建議文字
- 每月一筆紀錄,存在手機本機(離線也能用),可以看歷史紀錄

還是「示範用邏輯」、還沒有真正AI判斷的部分:
- 目前判斷「草有沒有超過膝蓋」,是用一個很簡單的替代邏輯:
  分析照片裡綠色像素佔的比例,超過一個門檻就判定為「偏高」。
  這不是真正訓練過的AI模型,只是讓整個流程可以先跑起來、
  拿去給人試用感受操作流程。
- 要換成真正的AI影像辨識(例如呼叫Claude或其他視覺模型API),
  技術上有一個限制:這個檔案是純前端網頁,沒有自己的伺服器。
  如果直接把API金鑰寫在這個網頁的程式碼裡,任何人打開網頁原始碼
  都能看到金鑰並盜用,所以正式上線前需要加一個小型後端
  (例如一個雲端function),由後端幫忙呼叫AI服務、網頁只跟自己的
  後端溝通,金鑰才不會外流。這塊如果你們要做,我可以接著幫忙寫。

三、要調整內容(不用改程式邏輯)
--------------------------------
打開 index.html,搜尋「設定區」,裡面有三個清楚標註可以自行修改的地方:
- GRASS_RULES:草高判斷的門檻
- SELF_ASSESS_QUESTIONS:農民自評的題目跟選項
- ADVICE_RULES:依不同狀況給的建議文字,可以自由增加規則

目前所有紀錄都存在農民手機的瀏覽器裡(localStorage),還沒有連到
後端資料庫,所以邱分院這邊還看不到農民回傳的資料。如果要讓資料
真的傳回你們這邊做彙整分析(串接氣象局、生產履歷、產出年度總評),
就是我們前面畫過的「後端資料處理流程」那張圖要做的事,這個需要
真正的伺服器跟資料庫,不是這個純前端網頁能完成的部分。
